### Featured Project

**[Question Paper Difficulty Analyzer](https://github.com/krish902/question-paper-difficulty-analyzer)**

Automated NLP pipeline using BERT to classify university exam questions by Bloom's Taxonomy cognitive levels and predict overall paper difficulty. Achieved 98.52% validation accuracy, outperforming LSTM (48.76%) and Bi-LSTM (67.32%). Published across 2 Springer conferences.
